## Objectives covered

- 3.1 — Explain concepts related to attack methodology frameworks
- 3.2 — Given a scenario, perform incident response activities

## Key concepts

### 3.1 Attack methodology frameworks

- [ ] MITRE ATT&CK (tactics, techniques, sub-techniques)
- [ ] The Cyber Kill Chain
- [ ] The Diamond Model of Intrusion Analysis
- [ ] OWASP Top 10 (web application context)
- [ ] How these frameworks are actually used during investigations (not just memorized)

### 3.2 Performing incident response activities

- [ ] Detection and analysis
- [ ] Containment strategies (segmentation, isolation, account disabling)
- [ ] Eradication (removing the root cause, not just symptoms)
- [ ] Recovery (restoring systems, validating integrity, monitoring for recurrence)
- [ ] Evidence handling and chain of custody basics
- [ ] Communication during an active incident (who gets told what, when)

### 3.3 Preparation and post-incident activity

- [ ] Incident response plan (IRP) and playbook development
- [ ] Tabletop exercises
- [ ] Roles and responsibilities (incident commander, analysts, legal, comms)
- [ ] Post-incident/lessons-learned review process
- [ ] Root cause analysis
- [ ] Metrics: MTTD (mean time to detect), MTTR (mean time to respond/recover)
- [ ] Alignment with NIST SP 800-61 (Computer Security Incident Handling Guide)
